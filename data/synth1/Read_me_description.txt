Description for each file

W_true_UV.csv :
True UV-vis spectrum used to generate the data in An_UV.csv. Each column corresponds to the spectrum of a compound, and each line corresponds to the absorbance at a specific wavelength (in eV).

H_true_UV_Raman.csv :
True concentration used to generate the data in An_UV.csv and An_Raman.csv. Each column corresponds to the time (in this case, the Li S ratio, proxy for time) at which a measurement was taken, and each line corresponds to a specific compound.

An_UV.csv :
Absorbance matrix, generated by matrix product (W_true_UV*H_true_UV_Raman), with added noise. Columns correspond to measurement time (in this case, Li S ratio, proxy for time), rows correspond to the wavelength (in eV).



W_true_Raman.csv :
True Raman spectrum used to generate the data in An_Raman.csv. Each column corresponds to the spectrum of a compound, and each line corresponds to the Raman spectrum at a specific Raman shift (cm-1).


An_Raman.csv.:
Raman matrix, generated by matrix product (W_true_Raman*H_true_UV_Raman), with added noise. Columns correspond to measurement time, rows correspond to the wavelength.

All the above data are synthetic data

An_UV_real.csv:

Real measured Absorbance matrix. Columns correspond to measurement time (in this case, Li S ratio, a proxy for time), and rows correspond to wavelength (in nm).   The number of components is 3.
