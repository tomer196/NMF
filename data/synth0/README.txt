Description for each file

W_true.csv :
True UV-vis spectrum used to generate the data in An.csv. 
Each column corresponds to the spectrum of a compound, each line correponds to the absorbance at a specific wavelength (in eV).

H_true.csv :
True concentration used to generate the data in An.csv. 
Each column corresponds to the time at which a measurement was take, each line corresponds to a specific compound.

An.csv :
Absorbance matrix, generated by matrix product (W_true*H_true), with added noise. 
Columns correspond to measurement time, rows correspond to the wavelength (in eV).



W_true_raman.csv :
True raman spectrum used to generate the data in An_raman.csv. 
Each column corresponds to the spectrum of a compound, each line correspond to the raman spectrum at a specific wavelength.

H_true_raman.csv :
True concentration used to generate the data in An_raman.csv. 
Essentially the same as H_true.csv, but binarized (value>1e-2 => 1) with added noise.

An_raman.csv :
Raman matrix, generated by matrix product (W_true_raman*H_true_raman), with added noise. 
Columns correspond to measurement time, rows correspond to the wavelength.


Half the measurements are missing in raman, but the data point number stay the same (so point number 2 in Raman is point number 2 in UV-vis, but point number 1 in UV-vis doesn't exist in Raman).
